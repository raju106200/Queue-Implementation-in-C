# Queue-Implementation-in-C
Implementation of a linear queue using an array in C with enqueue, dequeue, and display operations.


# Queue Implementation Using Array in C

## About
This project implements a linear queue using an array in C.

## Operations
- Enqueue: Insert an element into the queue.
- Dequeue: Delete an element from the queue.
- Display: Show all elements in the queue.
- Exit: Terminate the program.

## Concepts Used
- C Programming
- Arrays
- Functions
- FIFO (First In, First Out)

## How to Run
1. Compile the program:
   gcc queue.c -o queue

2. Run the program:
   ./queue
